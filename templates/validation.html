Standard K-Fold
sklearn.model_selection.KFold

Partitions dataset into k equally sized subsets. Each fold is held out once for validation while k-1 folds train the model.

Key Working Mechanics:
  • Configurable number of folds (default: 5 or 10).
  • Random shuffling with fixed seed for reproducibility.
  • Computes sample mean, variance, and individual fold scores.
Critical Hazard: Random partitioning can create severe class imbalance across test folds on skewed datasets.

Stratified K-Fold
sklearn.model_selection.StratifiedKFold

Rearranges the partitions so that each fold contains approximately the exact same percentage of each target class as the complete dataset.

Key Working Mechanics:
  • Strictly preserves class proportions in every training and validation fold.
  • Prevents rare-class dropouts in small or imbalanced datasets.
  • Significantly reduces estimator variance across folds.
Gold Standard: The recommended default validation method for classification.

Nested Cross-Validation
Double CV Loop

Decouples hyperparameter tuning from performance evaluation. Standard CV with grid tuning suffers from selection bias because parameters are chosen to maximize the test score.

Double-Loop Design:
  • Outer Loop: Evaluates genuine generalization error on isolated folds.
  • Inner Loop: Runs GridSearchCV strictly inside training folds to select optimal hyperparameters.
  • Outer test data is never touched during hyperparameter tuning.
Scientific Rigor: Eliminates selection bias, providing an honest performance estimate.

Time-Series Cross-Validation
sklearn.model_selection.TimeSeriesSplit

Evaluates sequential forecasting models using historical expanding windows. Observations are strictly ordered in time to prevent future lookahead leakage.

Temporal Constraint Rules:
  • Strictly chronological: Training window expands forward in time.
  • Zero random shuffling: Data sequence is never permuted.
  • Evaluated on MAE, RMSE, and zero-safe MAPE.
Never Apply K-Fold: Standard K-Fold leaks future information into past predictions, rendering evaluation invalid.
